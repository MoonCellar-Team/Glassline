# Редактор уровней Glassline

*English version — [README.md](README.md).*

Редактор собирает уровни для Glassline (вид сбоку) из частей самой игры: коробок и рамп, по которым
бегают, кусков палитры главы — домов, стен, кранов, вывесок, — сумок, чекпоинтов, тросов, турников и
музыки. В уровне хранится только разметка: модели, текстуры и звуки каждый игрок берёт из своей копии
игры, поэтому уровень весит несколько килобайт и ничего из игры в себе не несёт.

- [Интерфейс](interface.ru.md) — все панели, кнопки и сочетания клавиш: рейка инструментов, поле, карточка
  уровня, инспектор, область, вид сверху, палитра, мышь, клавиатура и касания.
- [Объекты](objects.ru.md) — как добавить каждый объект, что значат его настройки, и примеры по шагам:
  разрыв для прыжка, дом, билборд, по которому бегут, бег по стене, турник, поворачивающаяся тарелка
  чекпоинта и другое.
- [Уровни](levels.ru.md) — создание, сохранение и проверка уровня, вкладка «Уровни» лаунчера (выложить,
  обновить, взять с сервера, экспорт, импорт, удалить) и игра на уровнях — одному, онлайн и вдвоём.

## Как открыть редактор

- **PC:** в лаунчере вкладка **«Уровни»**. **«Создать уровень»** открывает редактор с формой нового уровня,
  **«Изменить»** у уровня — этот уровень. Редактор открывается своим окном, лаунчер остаётся.
- **Android:** те же кнопки на вкладке **«Уровни»**; редактор открывается на месте лаунчера и возвращается
  в него при выходе. Всё работает пальцами (см. [касания](interface.ru.md#касания)).

Редактору нужна копия игры, выбранная на вкладке **«Игра»**: палитра, картинки кусков и проверка уровня
берутся из неё.

## Быстрый старт

1. **«Создать уровень»** → id (латиница, цифры, `-` и `_`), основа — глава, **«Создать с нуля»**. В новом
   уровне есть пол, старт слева и финиш справа.
2. Инструмент **«Коробка»** на рейке слева (или `B`), щелчки по полю ставят коробки; тяните коробку —
   она двигается, тяните её край или угол — меняется размер.
3. Инструмент **«Кусок палитры»**, кусок в палитре, щелчок по полю — так уровень выглядит в игре. По
   коробкам бегают, куски — то, что видно.
4. Выберите коробку и нажмите **«Покрыть куском…»**: копии крыши или карниза лягут по её верху. Или дайте
   ей **поверхность** — фасад дома на всю коробку.
5. **«Проверить»** (`F5`): уровень сохраняется и запускается в игре. Закройте игру — вернётесь в редактор.
6. В лаунчере у уровня **«Выложить»** — поделиться им (нужен аккаунт MoonCellar).

## Размеры

Поле размечено в единицах игры. Движения Фейт — так, как их считает игра:

| Что | Размер |
|---|---|
| Скорость бега | 7 единиц в секунду |
| Высота прыжка | 1,3 |
| Прыжок с разбега по ровному | около 7 (удобный разрыв — 5) |
| Рост Фейт | 1,8 (бежать под потолком — нужно 2, прыгать — 3,1) |
| Ступенька без прыжка | 1 |
| Уступ, на который залезает в прыжке | до 2,3 (надёжно — 2) |
| Смертельное падение | около 16 вниз |
| Сумка, которую достаёт в прыжке | до 3,6 над полом |
| Турник с разбега | 3 над полом |

Сетка на поле — через 8 единиц, объекты встают с шагом 0,25.
